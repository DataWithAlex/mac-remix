# Documentation Guide

The `docs/` folder provides operational guidance for the mac-remix workflow. Use this index to jump straight to the information you need before each gig or import session.

| File | Description |
|------|-------------|
| `architecture.md` | High-level system design, dependencies, and decision log. |
| `preflight-mac.md` | macOS preparation checklist before the DDJ-FLX4 arrives. |
| `folder-structure.md` | Canonical folder and naming conventions (Tracks/Stems/Playlists). |
| `ingestion.md` | Deep dive on `djprep ingest`, metadata hygiene, and manifest management. |
| `stems.md` | Offline stem workflow with Demucs, plus best practices for Serato & rekordbox. |
| `normalization-export.md` | Loudness targets, ffmpeg-normalise usage, and MP3 export recipes. |
| `integration/serato.md` | Serato configuration, Smart Crates, and STEM pad mapping (DDJ-FLX4). |
| `integration/rekordbox.md` | rekordbox import, Intelligent Playlists, Track Separation mapping. |
| `integration/daws.md` | Getting stems into Ableton Live/Logic Pro and project templating. |
| `workflows/ingestion.md` | Quick action sheet mirroring the ingest workflow. |
| `workflows/daily-checklist.md` | Repeatable routine covering ingest → stems → tagging → export. |
| `workflows/usb-export.md` | Preparing club USB drives (rekordbox XML, Serato USB helper, verification). |

Each doc includes exact command lines, UI navigation (as of 28 Sep 2025), and integration pointers for the Pioneer DDJ-FLX4 controller.
